# 🚀 Скрипты развертывания CRM проекта

Созданы два скрипта для автоматизации развертывания и управления проектом:

- **`deploy.sh`** - для Linux/macOS
- **`deploy.ps1`** - для Windows PowerShell

## 📋 Быстрый запуск

### На Linux/macOS:
```bash
# Делаем скрипт исполняемым
chmod +x deploy.sh

# Полное развертывание проекта
./deploy.sh deploy

# Быстрое обновление
./deploy.sh update

# Показать справку
./deploy.sh help
```

### На Windows PowerShell:
```powershell
# Разрешаем выполнение скриптов (если нужно)
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# Полное развертывание проекта
.\deploy.ps1 deploy

# Быстрое обновление
.\deploy.ps1 update

# Показать справку
.\deploy.ps1 help
```

## 🛠️ Доступные команды

| Команда | Описание |
|---------|----------|
| `deploy` | Полное развертывание проекта |
| `update` | Быстрое обновление из репозитория |
| `start` | Запустить контейнеры |
| `stop` | Остановить контейнеры |
| `restart` | Перезапустить контейнеры |
| `rebuild` | Пересобрать и перезапустить |
| `status` | Показать статус сервисов |
| `logs` | Показать логи |
| `monitor` | Мониторинг в реальном времени |
| `migrate` | Применить миграции |
| `collectstatic` | Собрать статические файлы |
| `superuser` | Создать суперпользователя |
| `backup` | Создать резервную копию |
| `cleanup` | Очистка Docker ресурсов |
| `health` | Проверка работоспособности |

## 🔍 Что делает команда `deploy`

1. ✅ Проверяет наличие Docker и Docker Compose
2. ✅ Проверяет конфигурационные файлы (.env, docker-compose.yml)
3. 🛑 Останавливает и удаляет старые контейнеры
4. 🧹 Удаляет старые образы
5. 🔨 Собирает новые образы
6. 🚀 Запускает контейнеры
7. 🗄️ Применяет миграции базы данных
8. 📁 Собирает статические файлы
9. 🏥 Проверяет работоспособность
10. 👤 Предлагает создать суперпользователя

## 🔄 Что делает команда `update`

1. 🛑 Останавливает контейнеры
2. 📥 Получает обновления из git репозитория
3. 🔨 Пересобирает образы
4. 🚀 Запускает контейнеры
5. 🗄️ Применяет миграции
6. 📁 Собирает статические файлы
7. 🏥 Проверяет работоспособность

## 🌐 После успешного развертывания

- **Frontend**: http://localhost:8080
- **Backend API**: http://localhost:8000/api/
- **Admin панель**: http://localhost:8000/admin/
- **Healthcheck**: http://localhost:8000/health/ping/

## 📊 Мониторинг

```bash
# Статус всех сервисов
./deploy.sh status

# Логи в реальном времени
./deploy.sh monitor

# Проверка работоспособности
./deploy.sh health
```

## 💾 Резервное копирование

```bash
# Создать резервную копию volumes
./deploy.sh backup
```

Резервные копии сохраняются в папку `./backups/` с временной меткой.

## 🧹 Очистка

```bash
# Полная очистка Docker (осторожно!)
./deploy.sh cleanup
```

⚠️ **Внимание**: Команда `cleanup` удаляет ВСЕ неиспользуемые Docker ресурсы!

## 🐛 Решение проблем

1. **Контейнеры не запускаются**:
   ```bash
   ./deploy.sh logs
   ```

2. **Проблемы с базой данных**:
   ```bash
   ./deploy.sh migrate
   ```

3. **Проблемы со статикой**:
   ```bash
   ./deploy.sh collectstatic
   ```

4. **Полная перестройка**:
   ```bash
   ./deploy.sh stop
   ./deploy.sh cleanup
   ./deploy.sh deploy
   ```
